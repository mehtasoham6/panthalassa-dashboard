# Fonts

`SchmalfetteGrotesk.woff2` belongs here. It is the FAI display face and is
licensed, so it is not committed to this public repository; `.gitignore`
keeps it out. Ask Chris McCaffery for the file and drop it in this folder
before building or deploying.

The stylesheet loads it from `/fonts/SchmalfetteGrotesk.woff2`. Without the
file the headline falls back to Arial Narrow, which must not ship.
